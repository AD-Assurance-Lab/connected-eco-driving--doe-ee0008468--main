Description of Automated Systems Driving Toolbox Data Structures

CSU Vehicle Innovation Team

Aaron Rabinowitz

7/15/2019

Abstract:

This paper describes the various data structures used by the Automated Systems Driving Toolbox as well as some of the logic used by the classes in the toolbox. Finally this paper will describe the commonly used functions and what they allow the user to do. Ultimately all knowledge required to build custom constructors using the toolbox will be contained in this paper; examples of the development of said constructors will be contained in a separate paper.
