---------------------------------------------------------------FOV SCENARIOS------------------------------------------------------------------------

1. Open each of the files FOV_SCENARIO_X (X = 1, 2, 3, 4), limitation1, limitation2, Sensor_fusion1, Sensor_fusion2.
2. Run the files to watch the simulation.

The linear automated control (ACC) simulations ran on the EcoCAR vehicle model, which GM
supplied to EcoCAR teams. That model is not released, so those runs are not included.
