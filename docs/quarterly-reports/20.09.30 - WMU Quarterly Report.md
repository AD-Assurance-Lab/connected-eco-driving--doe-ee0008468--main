**Department of Energy Project: Quarterly Report**

**September 30th, 2020**

Our team has been focused on developing a global Optimal EMS code in python and also we have set up a deep neural network LSTM emission model. The dynamic programming method has been selected among other optimization methods which has shown promising results on improving fuel economy especially for HEVs and PHEVs[^1]. Our team getting close to finishing development and validating a low fidelity model of 2010 Toyota Prius over the fixed drive cycle which will be used to rigorously evaluate the effect of misprediction. It uses a dynamic equation from a force balance on the vehicle and a cost function of the mass of fuel used. We are currently validating the developed dynamic programming python code which then allows us to run the dynamic programming method using diverse high fidelity validated models on FastSim. For emission modeling we have prepared a recurrent deep neural network (DNN) model using long short term memory (LSTM) structure. Our future plan is to refine the model and validate it using test data gathered for different vehicles by the CSU team.

We have also begun development of a mathematical Eco-Driving algorithm that uses systems level data such as road speed limits and traffic light states to minimize acceleration (thus minimizing fuel consumption). Initial trajectory results for a downtown drive cycle are shown below.
