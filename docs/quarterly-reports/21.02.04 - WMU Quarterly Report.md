**Department of Energy Project: Quarterly Report**

**February 4th, 2021**

We have published a paper at SAE WCX world congress entitled “High-Fidelity Modeling of Light-Duty Vehicle Emission and Fuel Economy Using Deep Neural Networks''. In our latest machine learning study, an emission and fuel economy model for a diesel sedan vehicle were developed to accurately predict fuel consumption and emission rates using different deep neural networks and machine learning algorithms. In this study we observed that deep LSTM had promising and very accurate predictions compared to other algorithms which can be applied to other studies and other vehicle types. Also, we are currently working on model preparation of EMS optimization using dynamic programming on 2010 Toyota prius MATLAB model which hopefully can share the results on the next report.

We have begun development of a mathematical Eco-Driving algorithm that uses systems level data such as road speed limits and traffic light states to minimize acceleration (thus minimizing fuel consumption). We have been working on collecting data that can be used for the testing of the proposed method. Furthermore, we updated the control problem that was utilized in the paper and updated the description of the problem so that it can fit the real-world data collected.
